# Ranking de videojuegos
Aplicacion web para mostrar un ranking de videojuegos e informacion de los mismos.
Es un proyecto educativo para aprender a usar Express, ejs, HTML5, CSS3 y Javascript medio.

## Especificaciones tecnicas
- HTML5
- CSS3
- Vanilla Javascript (nada de Angular, React...)
- Maquetacion unicamente con flex (nada de grid)
- Estructura del proyecto original creado con generate-express
- Plantilla EJS

## Contenido
Usa contenido realista en ingles
Las imagenes usalas desde https://picsum.photos

## Buenas practicas
- Codigo en español
- Usa vanilla Javascript siempre
- Evita atributos de eventos
- Usar siempre classList
- Usar comentarios en plantillas
- Usar CSS anidado y variables cuando sea posible
